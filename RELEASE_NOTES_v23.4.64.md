# Team Calculator 23.4.64 — Firestore-first автосохранение

Основа: 23.4.63. Mac Connector 1.4.28, GitLab Label `Unexpected` и Firestore Rules из 23.4.63 не изменены.

## Изменения

- Удалена автоматическая запись аварийного плана в IndexedDB и его восстановление при входе. Нет сравнения времени локальной копии с `app/main`, нет диалога «Есть несохранённая локальная копия плана».
- При открытии приложения сохранённый общий спринт загружается с сервера Firestore и имеет приоритет над персональным `users/{uid}/app/main`. Сортировка общего пула остаётся персональной. Если общего спринта нет, устаревшая персональная копия не создаёт его повторно.
- Изменения сохраняются с задержкой 1 с после последнего изменения; для редактируемого именованного спринта сначала подтверждается запись общего спринта, затем персонального текущего состояния. Прежняя атомарная запись спринта и связей задач, чанки и проверка контрольной суммы сохранены.
- Ошибка сохранения не приводит к загрузке другой копии. Пока вкладка открыта, повтор выполняется автоматически (интервал при отказах 5–60 с), при восстановлении сети и при скрытии вкладки. Изменения во время выполняющейся записи сохраняются следующим циклом.
- Переход между спринтами, перезагрузка данных из Firestore, выход, копирование и удаление не должны оставлять несохранённый план. Если запись ещё выполняется или не прошла, нужно повторить действие после подтверждения сохранения. При попытке закрыть страницу с незаписанными изменениями браузер может показать стандартное предупреждение; при сохранённом плане оно не вызывается.
- Отдельная функция «Вернуть предыдущий план» (история действий в localStorage) сохранена, как и подтверждения явного сброса/завершения/удаления. Старые аварийные записи IndexedDB не читаются и не удаляются автоматически, чтобы не уничтожить возможные несохранённые данные от прежней версии. Новые аварийные копии не создаются.

## Обновление

Если 23.4.63 уже установлена, обновить только `index.html` (и файлы версии/документации в репозитории). Изменений конфигурации, правил, коннектора и схемы Firestore нет. Если обновление выполняется с 23.4.62, сначала применить комплект 23.4.63: правила и Mac Connector 1.4.28.

## Проверка

- `node tests/test_storage.cjs`
- `node tests/test_unexpected.cjs`
- `node tests/test_cloud_autosave.cjs`
- `CHROMIUM_PATH=/usr/bin/chromium python tests/test_unexpected_browser.py`
- `CHROMIUM_PATH=/usr/bin/chromium python tests/test_cloud_startup_browser.py`

Тесты используют имитацию Firestore, браузерные тесты — Chromium без подключения к Firebase. Промышленная проверка не выполнена. Запись в Firestore не может быть гарантирована при закрытии вкладки до подтверждения или при аварийном завершении браузера. Автосохранение в фоне после закрытия страницы не предусмотрено. Для первоначальной загрузки общего спринта требуется доступ к серверу Firestore. Одновременное редактирование одного спринта несколькими вкладками не защищено новой системой разрешения конфликтов.
